# 二、考试必须背的定义（名词解释）

# 1. 网络空间（Cyberspace）

```text
网络空间是所有信息系统的集合，
是人类生存的信息环境，
人在其中与信息相互作用相互影响。
```

------

# 2. 信息安全三大属性

```text
信息安全包括：
保密性、完整性和可用性，
这三大属性是信息安全的基石。
```

------

# 3. 数据安全

```text
数据安全是指采取措施确保数据免受未授权泄露、
篡改和毁坏。
```

------

# 4. 内容安全

```text
内容安全是信息安全在法律、
政治和道德层次上的要求。
```

------

# 5. 行为安全

```text
行为安全是信息安全的终极目的，
包括行为的秘密性、
完整性和可控性。
```

# 三、必须背的简答题（直接默写）

# 1. 网络安全观（超级重点）

```text
树立正确网络安全观要认识到：

1）网络安全是整体的，而不是孤立的；
2）网络安全是动态的，而不是静态的；
3）网络安全是开放的，而不是封闭的；
4）网络安全是相对的，而不是绝对的；
5）网络安全是共同的，而不是孤立的。
```

------

# 2. 网络信息安全三个级别

```text
网络信息安全包括三个级别：

1）计算机安全是信息安全的基础；

2）网络安全是信息安全的核心；

3）信息系统安全是信息安全的目标。
```

------

# 3. 信息安全发展四阶段（必考）

```text
信息安全发展主要经历四个阶段：

1）通信保密阶段：
20世纪40年代，
重点研究数据加密和通信保密。

2）计算机安全阶段：
20世纪80年代，
重点研究访问控制，
防止非授权访问。

3）信息系统安全阶段：
20世纪90年代，
重点关注整个信息系统安全，
保证保密性、完整性、可用性和不可否认性。

4）网络空间安全阶段：
21世纪，
网络空间成为国家安全的重要组成部分，
重点关注运行安全和意识形态安全。
```

------

# 4. 信息安全三大属性（CIA）

```text
信息安全三大属性包括：

1）保密性（Confidentiality）：
保证信息不被未授权用户获取。

2）完整性（Integrity）：
保证信息不被非法修改和破坏。

3）可用性（Availability）：
保证合法用户能够正常访问和使用信息系统。

这三大属性是信息安全的基础。
```

------

# 5. 信息系统安全组成（重点）

```text
信息系统安全包括：

1）设备安全：
保证设备稳定性、可靠性和可用性。

2）数据安全：
保证数据的秘密性、完整性和可用性。

3）内容安全：
保证信息内容符合法律、政治和道德要求。

4）行为安全：
保证行为的秘密性、完整性和可控性。

其中，设备安全是首要问题，
行为安全是信息安全的终极目的。
```

------

# 6. 网络主要威胁

```text
网络面临的主要威胁包括：

1）恶意攻击；
2）软件漏洞；
3）网络结构缺陷；
4）安全缺陷；
5）自然灾害。
```

------

# 7. 信息安全技术特点

```text
信息安全技术具有：

1）底层性：
必须从硬件和操作系统等底层采取安全措施。

2）整体性：
必须从整体上综合考虑信息安全问题。

3）系统性：
信息安全是一个系统工程，
需要技术、管理、法律和教育等多方面共同配合。
```

------

# 8. 木桶原理

```text
信息安全遵从木桶原理，
系统整体安全水平取决于最薄弱环节。

只要系统中存在某个安全短板，
攻击者就可能从该弱点突破整个系统。
```
