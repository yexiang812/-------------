# 二、考试必须背的定义（名词解释）

# 1. 网络攻击

```text
网络攻击是指以互联网为媒介，
试图渗透或绕过系统安全策略，
在未授权情况下使用网络资源、
获取信息、更改信息或中断系统正常运行的行为。
```

------

# 2. 扫描器

```text
扫描器是一种自动检测远程或本地主机安全弱点的程序。
```

------

# 3. Sniffer

```text
Sniffer是一种网络监听工具，
通过将网卡设置为混杂模式监听网络数据。
```

------

# 4. 字典攻击

```text
字典攻击是指利用常见密码字典文件，
反复猜测用户密码的一种攻击方式。
```

------

# 5. 强行攻击（暴力破解）

```text
强行攻击是指尝试所有可能字符组合，
最终破解密码的一种攻击方式。
```

------

# 6. 组合攻击

```text
组合攻击是指在字典单词后组合数字和字符进行密码破解。
```

# 三、必须背的简答题（直接默写）

# 1. 网络攻击三个阶段（超级重点）

```text
网络攻击一般分为三个阶段：

1）攻击准备阶段：
确定攻击目标，准备攻击工具，收集目标信息。

2）攻击实施阶段：
隐藏攻击位置，利用各种手段登录目标计算机，
利用漏洞或后门获取控制权。

3）攻击善后阶段：
消除攻击痕迹，植入后门并退出系统。
```

------

# 2. 网络扫描（重点）

```text
网络扫描是指利用扫描器自动检测目标系统安全弱点的过程。

扫描器通过向目标主机发送数据报文，
根据目标返回的信息分析系统情况。

网络扫描主要包括：
1）地址扫描；
2）端口扫描；
3）漏洞扫描。

网络扫描可以发现目标系统的操作系统、
开放端口、服务及可能存在的漏洞，
从而为进一步攻击打下基础。
```

------

# 3. Sniffer 工作原理（必背）

```text
Sniffer是一种网络监听工具。

其工作原理是将本地网卡设置为
Promiscuous（混杂）模式。

在这种模式下，
主机能够接收网络中传输的所有数据帧，
无论数据是否发给本机。

Sniffer通过分析数据包，
能够获取用户名、密码等重要信息。
```

------

# 4. 口令破解方式（重点）

```text
口令破解是指攻击者通过猜测或计算用户密码，
从而获取系统访问权限。

常见口令攻击方式包括：

1）字典攻击：
利用常见密码字典进行猜测，
速度快，但只能破解常见密码。

2）强行攻击：
尝试所有可能的字符组合，
理论上可破解所有密码，
但耗时较长。

3）组合攻击：
使用字典单词并组合数字和字符进行破解。
```

# 五、判断题最容易错（必须看）

# 正确

✅ 攻击本质包括破坏和入侵
✅ 网络扫描属于攻击前侦察
✅ 端口扫描可发现服务信息
✅ Sniffer 基于混杂模式
✅ 网络监听属于被动攻击
✅ 字典攻击速度快
✅ 理论上任何密码都能破解

------

# 错误

❌ 扫描器本身一定是攻击软件
❌ 混杂模式只接收本机数据
❌ Sniffer 很容易发现
❌ 字典攻击能破解所有密码
❌ 强行攻击速度最快
❌ 强密码绝对无法破解
