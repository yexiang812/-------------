# 二、考试必须背的定义（名词解释）

# 1. DoS

```text
拒绝服务攻击（DoS）是指攻击者通过消耗目标系统资源，
使目标系统无法继续提供正常服务的一种攻击方式。
```

------

# 2. DDoS

```text
分布式拒绝服务攻击（DDoS）是指攻击者控制多台主机，
同时对目标系统发起拒绝服务攻击。
```

------

# 3. 缓冲区溢出

```text
缓冲区溢出是指向缓冲区写入超过其容量的数据，
从而覆盖其他内存区域并执行恶意代码的一种攻击。
```

------

# 4. 木马

```text
木马是附着在应用程序中或独立存在的恶意程序，
可实现远程控制和窃取信息。
```

------

# 5. DNS 欺骗

```text
DNS欺骗是指攻击者伪造DNS解析结果，
将用户引导到错误网站的一种攻击。
```

------

# 6. XSS

```text
XSS即跨站脚本攻击，
是一种利用恶意脚本攻击用户浏览器的Web攻击方式。
```

------

# 7. IP 欺骗

```text
IP欺骗是指攻击者通过伪造可信IP地址，
利用主机之间信任关系进行攻击。
```

# 三、必须背的简答题（直接默写）

# 1. SYN Flood 原理（超级重点）

```text
SYN Flood是一种拒绝服务攻击。

其原理是利用TCP三次握手缺陷，
攻击者向目标系统发送大量伪造的SYN请求，
但不完成连接建立。

服务器会为这些半连接分配资源，
最终导致系统资源耗尽，
使合法用户无法正常访问系统。
```

------

# 2. DDoS 攻击（高频）

```text
DDoS即分布式拒绝服务攻击，
是对传统DoS攻击的发展。

攻击者首先侵入并控制大量计算机，
然后控制这些主机同时向目标系统发起攻击，
从而消耗目标系统资源，
使合法用户无法正常访问系统。

DDoS具有攻击流量大、
隐蔽性强、
难以防御等特点。
```

------

# 3. 缓冲区溢出原理及危害（必考）

```text
缓冲区溢出是由于程序没有检查输入数据长度，
向缓冲区写入超长数据导致的。

溢出后可能覆盖其他内存区域，
使程序执行恶意代码。

其危害包括：
1）程序崩溃；
2）系统死机；
3）攻击者获取系统权限。
```

------

# 4. 木马攻击原理（重点）

```text
木马是附着在应用程序中或独立存在的恶意程序。

木马利用TCP/IP协议，
采用C/S结构。

服务端运行于受害主机，
客户端运行于攻击者主机。

攻击者通过网络向木马发送命令，
从而实现对受害主机的远程控制，
并窃取机密信息。
```

------

# 5. DNS 欺骗原理（重点）

```text
DNS欺骗是指攻击者截获DNS解析请求，
并向请求者返回伪造的IP地址。

用户会根据错误的IP地址访问假网站，
从而导致账号、密码等重要信息泄露。
```

------

# 6. XSS 攻击（高频）

```text
XSS即跨站脚本攻击，
是一种Web攻击方式。

攻击者通过在网页中插入恶意脚本代码，
当用户访问网页时，
脚本会在用户浏览器中自动执行。

XSS可能导致Cookie泄露、
页面跳转、
恶意程序下载等安全问题。
```

------

# 7. IP 欺骗原理（重点）

```text
IP欺骗是指攻击者通过伪造可信IP地址，
利用主机之间的信任关系进行攻击。

攻击者首先使可信主机失效，
然后伪造可信主机IP地址与目标系统建立连接，
最终冒充可信主机向目标系统发送命令。
```

------

# 四、综合题流程（直接背）

# 1. DNS 欺骗流程

```text
1）用户发送DNS请求；
2）攻击者截获请求；
3）返回伪造IP地址；
4）用户访问假网站；
5）攻击者窃取信息。
```

------

# 2. IP 欺骗流程

```text
1）使可信主机失效；
2）猜测TCP序列号；
3）伪造可信IP地址；
4）建立连接；
5）发送攻击命令。
```

------

# 3. Smurf 攻击流程

```text
1）伪造受害者IP；
2）向广播地址发送ICMP请求；
3）网络所有主机回复；
4）大量数据淹没受害者。
```

# 六、判断题最容易错（必须看）

# 正确

✅ SYN Flood 属于 DoS
✅ DDoS 隐蔽性更强
✅ 缓冲区溢出属于软件漏洞
✅ 木马采用 C/S 结构
✅ DNS 欺骗返回假IP
✅ XSS 利用恶意脚本
✅ IP 欺骗利用信任关系

------

# 错误

❌ SYN Flood 属于木马攻击
❌ DDoS 只有一个攻击源
❌ 缓冲区溢出不会覆盖内存
❌ 木马不能远程控制
❌ DNS 欺骗属于 DoS
❌ XSS 不属于 Web 攻击
❌ IP 欺骗返回假域名
