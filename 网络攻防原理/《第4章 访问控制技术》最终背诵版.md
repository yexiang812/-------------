# 三、必须背的简答题（直接默写）

# 1. DAC 与 MAC 区别（超级重点）

```text
DAC即自主访问控制，
由资源拥有者自主决定其他用户的访问权限，
具有灵活方便的特点，
但权限容易滥用，安全性较低。

MAC即强制访问控制，
由系统根据安全属性强制决定用户访问权限，
用户不能修改权限，
安全性较高，但灵活性较差。
```

------

# 2. BLP 模型（必考）

```text
BLP模型是一种用于保护信息保密性的强制访问控制模型。

BLP模型包括两条规则：

1）简单安全规则：
主体只能读取密级低于或等于自己的客体，
即“从下读”。

2）星规则：
主体只能向密级高于或等于自己的客体写入，
即“向上写”。

BLP模型通过“下读上写”机制，
防止机密信息泄漏。
```

------

# 3. Biba 模型（高频）

```text
Biba模型是一种用于保护信息完整性的访问控制模型。

Biba模型的访问控制规则与BLP模型相反。

1）简单完整性规则：
主体只能向完整性级别低于或等于自己的客体写入，
即“向下写”。

2）完整性制约规则：
主体只能读取完整性级别高于或等于自己的客体，
即“从上读”。

Biba模型通过“上读下写”机制，
防止低完整性数据污染高完整性数据。
```

------

# 4. RBAC 模型（必背）

```text
RBAC即基于角色的访问控制模型。

RBAC在用户与权限之间引入角色概念，
用户通过角色获得权限。

RBAC模型的核心结构为：
用户→角色→权限。

RBAC具有管理方便、
适合大型组织、
安全性高等优点。

RBAC遵循最小权限原则和责任分离原则。
```

------

# 5. 身份认证（常考）

```text
身份认证是指当用户访问系统资源时，
系统验证用户身份真实性的过程。

身份认证是访问控制的前提，
也是权限判断和责任追踪的基础。

身份认证的依据主要包括：
1）用户知道的信息（密码）；
2）用户拥有的物品（智能卡）；
3）用户生物特征（指纹、人脸）；
4）可信第三方；
5）特定地点或时间。
```

------

# 6. 物理隔离（常考）

```text
物理隔离是指将内网与外网从物理上断开，
但保持适度逻辑连接的一种安全技术。

物理隔离通过专用硬件设备，
防止外部网络直接访问内部系统，
从而提高系统安全性。

物理隔离技术包括：
网络安全隔离卡、
集线器级隔离、
网络隔离网闸、
服务器端隔离等。

其优点是安全级别高；
缺点是资源消耗大，
管理不方便，
并会影响应用功能。
```

# 五、判断题最容易错（必须看）

# 正确

✅ BLP：下读上写
✅ Biba：上读下写
✅ RBAC 基于角色
✅ MAC 安全性高于 DAC
✅ 物理隔离安全级别高

------

# 错误

❌ BLP 保护完整性
❌ Biba 保护保密性
❌ DAC 由系统强制控制
❌ RBAC 中用户直接获得权限
❌ 物理隔离允许直接联网
