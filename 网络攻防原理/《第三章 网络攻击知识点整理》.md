------

# 1. 什么是拒绝服务攻击 DoS？

DoS 全称：

```text
Denial of Service
```

中文：

```text
拒绝服务攻击
```

老师资料里的定义是：

> 攻击者让目标机器停止提供服务，阻止或拒绝合法用户访问网络服务器。

简单理解：

```text
让服务器忙到崩溃，正常用户进不去
```

------

# 2. 举个例子

比如学校教务系统：

正常情况：

```text
学生登录 → 查成绩 → 系统正常响应
```

DoS 攻击时：

```text
攻击者疯狂发送请求
→ 服务器处理不过来
→ 正常学生无法登录
```

这就是拒绝服务。

------

# 3. DoS 的目的

DoS 不是为了偷数据，而是为了：

```text
让系统不能正常服务
```

常见结果：

```text
网站打不开
系统卡死
服务器宕机
网络堵塞
```

------

# 4. DoS 攻击常见方式

资料里说主要包括：

```text
资源消耗
服务中止
物理破坏
利用程序错误使服务失效
```

考试最常考的是：

```text
资源消耗
```

比如：

```text
CPU耗尽
内存耗尽
连接队列占满
带宽占满
```

------

# 5. DoS 的核心思想

一句话：

```text
消耗目标资源，使合法用户无法访问
```

------

# 6. 考试怎么答？

```text
使目标机器停止提供服务，
```

# 二、先理解 TCP 三次握手（必须懂）

这是 SYN Flood 的基础。

------

# 正常建立连接过程

假设：

```text
客户端 想连接 服务器
```

会经历：

------

# 第一步：客户端发送 SYN

意思：

```text
“我想建立连接”
```

------

# 第二步：服务器回复 SYN + ACK

意思：

```text
“收到，你确认一下”
```

------

# 第三步：客户端回复 ACK

意思：

```text
“确认，连接建立”
```

------

# 这就叫：

```text
TCP 三次握手
```

考试必背：

```text
SYN → SYN+ACK → ACK
```

------

# 三、SYN Flood 怎么攻击？

攻击者：

```text
只做前两步
```

不做：

```text
最后确认
```

------

# 攻击过程

------

# 第一步

攻击者疯狂发送：

```text
SYN 请求
```

------

# 第二步

服务器收到后：

```text
为每个连接分配资源
```

并回复：

```text
SYN+ACK
```

------

# 第三步

攻击者：

```text
不回复 ACK
```

------

# 结果

服务器会一直等待。

这些连接：

```text
叫“半连接”
```

------

# 四、为什么服务器会崩？

因为：

服务器：

```text
每个半连接都要占资源
```

例如：

- 内存
- CPU
- 连接队列

------

# 攻击者大量发送 SYN 后：

```text
半连接越来越多
```

最终：

```text
服务器资源耗尽
```

导致：

```text
正常用户无法连接
```

------

# 五、最核心一句话（必须背）

# SYN Flood：

```text
利用 TCP 三次握手缺陷，
制造大量半连接，
耗尽系统资源。
```


# “简述 SYN Flood 原理”

```text

攻击者向目标系统发送大量伪造的SYN请求，

服务器会为这些半连接分配资源，
最终导致系统资源耗尽，
使合法用户无法正常访问系统。
```

# 二、先理解 ICMP

ICMP：

```text
网络控制消息协议
```

最经典：

```text
ping
```

其实就是 ICMP。

------

# ping 做了什么？

你 ping 百度：

```text
发送 ICMP 请求
```

对方：

```text
回复 ICMP 应答
```

------

# 三、什么叫“广播”？

广播：

```text
给整个网络所有主机发消息
```

例如：

```text
192.168.1.255
```

广播地址。

------

# 四、Smurf 怎么攻击？

这是重点。

------

# 第一步：伪造 IP 地址

攻击者：

```text
把“源地址”伪装成受害者IP
```

这叫：

```text
IP欺骗
```

------

# 第二步：发送广播 ICMP

攻击者向：

```text
广播地址
```

发送：

```text
ICMP 请求（ping）
```

------

# 第三步：整个网络都回复

因为是广播。

所以：

```text
网络里所有主机
```

都会回复：

```text
ICMP 应答
```

------

# 第四步：全部回复受害者

因为源 IP 被伪造成：

```text
受害者地址
```

于是：

```text
所有回复都打向受害者
```

------

# 五、最终结果

受害者突然收到：

```text
海量 ICMP 数据
```

导致：

- 网络堵塞
- 带宽耗尽
- 系统崩溃

------

# 六、为什么 Smurf 很厉害？

```text

```

攻击者：

```text

```

但：

```text
几百台主机一起回复
```

这就是：

```text
广播放大攻击
```

# Smurf：


# 二、什么叫“溢出”？

假设：


```text

```

# 十一、考试简答标准答案

# “简述 IP 欺骗原理”

```text
IP欺骗是指攻击者通过伪造可信IP地址，
利用主机之间的信任关系进行攻击。

攻击者首先使可信主机失效，
然后伪造可信主机IP地址与目标系统建立连接，
最终冒充可信主机向目标系统发送命令。
```
