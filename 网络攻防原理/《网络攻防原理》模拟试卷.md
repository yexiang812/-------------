## 二、名词解释答案

### 1. DoS 攻击

拒绝服务攻击是指攻击者通过消耗目标系统资源，使目标机器停止提供服务，从而阻止合法用户访问网络服务器的一种破坏性攻击方式。

### 2. 缓冲区溢出

缓冲区溢出是指向缓冲区写入超过其容量的数据，导致覆盖其他内存区域，并可能执行恶意代码的一种攻击方式。

### 3. Sniffer

Sniffer 是一种网络监听工具，通过将网卡设置为混杂模式，监听网络中传输的数据帧，从而获取通信内容。

### 4. RBAC

RBAC 即基于角色的访问控制，通过在用户和权限之间引入角色，使用户通过角色获得相应访问权限。

### 5. DNS 欺骗

DNS 欺骗是指攻击者伪造 DNS 解析结果，向用户返回虚假的 IP 地址，使用户访问错误网站的一种欺骗攻击。

## 五、简答题参考答案

### 1. 简述信息安全的三大属性。

信息安全三大属性包括：

1）保密性：保证信息不被未授权用户获取。
2）完整性：保证信息不被非法修改和破坏。
3）可用性：保证合法用户能够正常访问和使用信息系统。

这三大属性是信息安全的基础。

------

### 2. 简述网络攻击的一般步骤。

网络攻击一般分为三个阶段：

1）攻击准备阶段：确定攻击目标，准备攻击工具，收集目标信息。
2）攻击实施阶段：隐藏攻击位置，利用各种手段登录目标计算机，并利用漏洞或后门获取控制权。
3）攻击善后阶段：消除攻击痕迹，植入后门并退出系统。

------

### 3. 简述 SYN Flood 攻击的基本原理。

SYN Flood 是一种拒绝服务攻击。

其原理是利用 TCP 三次握手缺陷，攻击者向目标系统发送大量伪造的 SYN 请求，但不完成连接建立。

服务器会为这些半连接分配资源，最终导致系统资源耗尽，使合法用户无法正常访问系统。

------

### 4. 简述缓冲区溢出的原理及危害。

缓冲区溢出是由于程序没有检查输入数据长度，向缓冲区写入超长数据导致的。

溢出后可能覆盖其他内存区域，使程序执行攻击者预设的恶意代码。

其危害包括：

1）程序崩溃；
2）系统死机；
3）攻击者可能获取系统权限。

------

### 5. 简述 DAC 与 MAC 的区别。

DAC 即自主访问控制，由资源拥有者自主决定其他用户的访问权限，具有灵活方便的特点，但权限容易被滥用，安全性较低。

MAC 即强制访问控制，由系统根据安全属性强制决定用户访问权限，用户不能随意修改权限，安全性较高，但灵活性较差。

------

## 六、综合题参考答案

### 1. DNS 欺骗

1）DNS 的作用是进行域名解析，即把用户输入的域名转换为对应的 IP 地址。

2）DNS 欺骗的基本过程是：

```text
用户发送 DNS 请求
攻击者截获请求
攻击者返回伪造 IP 地址
用户根据假 IP 访问伪造网站
攻击者窃取用户信息
```

3）DNS 欺骗的危害包括：

```text
用户被引导到假网站
账号密码等敏感信息泄露
用户无法访问真实网站
可能进一步遭受木马或钓鱼攻击
```

------

### 2. 访问控制模型

1）该系统体现的是 BLP 模型，即 Bell-LaPadula 模型。

2）BLP 模型主要保护信息的保密性。

3）BLP 模型的两条核心规则是：

```text
简单安全规则：主体只能读取密级低于或等于自己的客体，即从下读。

星规则：主体只能向密级高于或等于自己的客体写入，即向上写。
```

也可以概括为：

```text
下读上写
```

4）BLP 模型的优点是：能够保证信息向高安全级别方向单向流动，防止机密信息向低级别泄露。

不足是：应用领域较窄，使用不够灵活，主要强调保密性，对完整性控制不足。
