## 二、名词解释答案

### 1. 网络空间

网络空间是所有信息系统的集合，是人类生存的信息环境，人在其中与信息相互作用、相互影响。

------

### 2. 字典攻击

字典攻击是指攻击者利用包含常见口令的字典文件，反复尝试用户密码的一种口令攻击方式。

------

### 3. Smurf 攻击

Smurf 攻击是一种拒绝服务攻击，攻击者利用 IP 欺骗和 ICMP 广播，使大量 ICMP 应答数据淹没受害主机，导致网络阻塞或服务不可用。

------

### 4. 木马

木马是附着在应用程序中或独立存在的恶意程序，可以实现远程控制目标计算机或窃取机密信息。

------

### 5. 物理隔离

物理隔离是指将内网与外网从物理上断开，但保持适度逻辑连接，以提高系统安全性的一种技术。

## 五、简答题参考答案

### 1. 简述正确的网络安全观。

正确的网络安全观包括：

1）网络安全是整体的，不是孤立的；
2）网络安全是动态的，不是静态的；
3）网络安全是开放的，不是封闭的；
4）网络安全是相对的，不是绝对的；
5）网络安全是共同的，不是孤立的。

------

### 2. 简述信息系统安全的组成。

信息系统安全包括：

1）设备安全：保证设备的稳定性、可靠性和可用性；
2）数据安全：保证数据的秘密性、完整性和可用性；
3）内容安全：保证信息内容符合法律、政治和道德要求；
4）行为安全：保证行为的秘密性、完整性和可控性。

其中，设备安全是首要问题，行为安全是信息安全的终极目的。

------

### 3. 简述网络扫描的类型及作用。

网络扫描是利用扫描器自动检测目标系统安全弱点的过程。

网络扫描主要包括：

1）地址扫描：用于发现目标主机是否存活；
2）端口扫描：用于发现目标开放的端口、服务和应用程序信息；
3）漏洞扫描：用于发现目标系统可能存在的安全漏洞。

网络扫描可以为进一步攻击提供目标系统信息。

------

### 4. 简述口令破解的主要方式。

口令破解主要包括：

1）字典攻击：利用常见密码字典进行尝试，速度快，但只能破解常见口令；
2）强行攻击：尝试字母、数字、特殊字符的所有组合，理论上可破解所有密码，但耗时长；
3）组合攻击：使用字典单词，并在其后组合数字或字符进行破解。

------

### 5. 简述 Biba 模型的基本思想和规则。

Biba 模型是一种保护信息完整性的访问控制模型，其访问控制规则与 BLP 模型相反。

Biba 模型包括两条规则：

1）简单完整性规则：主体只能向完整性级别低于或等于自己的客体写入，即“向下写”；
2）完整性制约规则：主体只能读取完整性级别高于或等于自己的客体，即“从上读”。

因此，Biba 模型可概括为“上读下写”，用于防止低完整性数据污染高完整性数据。

## 六、综合题参考答案

### 1. 木马攻击

1）木马是附着在应用程序中或独立存在的恶意程序，可以实现远程控制和窃取信息。

2）木马通常采用 C/S 结构，即客户端/服务器结构。服务端运行在受害主机上，客户端运行在攻击者主机上。

3）木马可以实现远程控制、密码窃取、键盘记录、屏幕监视、鼠标键盘控制、文件破坏等功能。

4）反弹型木马会由受害主机主动向攻击者主机发起连接，而防火墙通常信任内部主机主动发起的连接，因此可能绕过防火墙限制。

------

### 2. IP 欺骗

1）IP 欺骗是指攻击者伪造可信 IP 地址，冒充可信主机进行攻击。

2）IP 欺骗利用的是主机之间基于 IP 地址的信任关系。

3）IP 欺骗的一般过程包括：

```text
1）暂时使可信主机失效；
2）连接目标主机端口并猜测 TCP 序列号；
3）伪造可信主机 IP 地址发送 SYN 请求；
4）继续伪造 ACK 完成连接；
5）冒充可信主机发送命令。
```

4）仅依靠 IP 地址判断身份不安全，因为 IP 地址可能被伪造。攻击者可以冒充可信主机绕过认证，因此系统还应结合身份认证、访问控制、加密等机制。
